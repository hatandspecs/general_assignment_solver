# Medium Example — Notes

Informal notes, preserved as the original record of intent. See
`examples/medium_example/README.md` for how the example actually turned out.

This example should include 50 personnel and between 10 and 12 simultaneous
projects.

Personnel salaries should be randomly selected between 100k - 250k per year.

The projects should range from 6 month PoPs to 18 month PoPs, and some of them
should span the UFY (the corporate fiscal year).

The project wrap rate should be a random number for each UFY that is around
2.9% +/- 2%, and this rate should only change on July 1 (the start of the
corporate fiscal year UFY).

Personnel salaries should increase by a percentage each October, randomly
selected between 1% and 4%.

For this example, the workable hours in each month should be based on openly
available corporate/government calendar data, respecting federal holidays.

The first year in the example will start on calendar year (CY) 2027, and the
demo should span 5 CY so that numerous UFY transitions can be examined.

Randomly generate a full set of workers and projects using worker names like
firstname_1, lastname_1 and project_1, project_1b (a continuation of
project_1), project_2, project_3, project_3b, project_3c, etc.

Of the 50 personnel, 35 of them should be full time (100% FTE) on the projects
in the group of projects — these represent dedicated staff in the unit doing
the planning. 10 of them should be 75% time, meaning they can work 75% of the
workable hours in a month on the portfolio of projects. 5 of them should be
25% time.
